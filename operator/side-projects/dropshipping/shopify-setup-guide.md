# CalmPaws — Shopify Setup Guide (paste-by-paste)

There is no "code import." You build the store in Shopify's visual editor and paste the
copy from `store-copy.md` into the right spots. No technical skill needed. Follow in order.
Budget about 60 to 90 minutes the first time.

---

## Step 1: Create the store (5 min)
1. Go to **shopify.com** and click **Start free trial**.
2. Answer the quick questions fast (or skip them). You don't need to be perfect here.
3. Name the store **CalmPaws**. You now have an admin dashboard. Done.

## Step 2: Add your product (15 min)
Admin → **Products** → **Add product**.
- **Title:** paste the product title from `store-copy.md` → `CalmPaws Calming Cloud Bed | Anti-Anxiety Pet Bed`
- **Description:** paste the **Long description** from the product-page section.
- **Media:** upload your product photos (from your supplier or your sample). Get 4 to 6 good ones.
- **Pricing:** Price `34.95`, Compare-at price `59.95`.
- **Variants:** click **Add options like size** → option name `Size`, values `Small`, `Medium`, `Large`.
- **Inventory:** if you don't want to track stock, uncheck "track quantity" so it never shows sold out.
- Click **Save**.

## Step 3: Pick the theme (2 min)
Admin → **Online Store** → **Themes**. The free **Dawn** theme is already there. Click
**Customize** to open the visual editor (this is where you build the homepage).

## Step 4: Build the homepage (20 min)
In the theme editor you **add sections** and paste copy from the Homepage part of
`store-copy.md`. Click **Add section** for each:

| Add this section | Paste this from store-copy.md |
|---|---|
| Announcement bar (top) | The announcement bar line |
| Image banner | Hero headline + subhead + button text "Calm My Pup" |
| Rich text | The "Problem section" headline + body |
| Image with text | The "Solution section" |
| Multicolumn (3 cols) | The "How it helps" 3 points |
| Featured product | Select your Calming Cloud Bed |
| Multicolumn or reviews app | The review quotes (seed 6 to 8) |
| Rich text | The "Guarantee section" |
| Image banner | The "Final CTA" |

Tip: drag sections to reorder. Hit **Save** often.

## Step 5: Create the pages (10 min)
Admin → **Online Store** → **Pages** → **Add page** for each:
- **About** → paste the About page copy.
- **FAQ** → paste the product-page FAQ (or make a dedicated FAQ page).
- **Contact** → Shopify has a contact page template; add your support email.

## Step 6: Set up policies (5 min)
Admin → **Settings** → **Policies**. Shopify can **auto-generate** Refund, Privacy, Terms,
and Shipping policies. Generate them, then edit the Shipping and Refund ones to match the
30-day guarantee and your supplier's real shipping times (from `store-copy.md`).

## Step 7: Navigation menu (5 min)
Admin → **Online Store** → **Navigation**. Add menu links: Home, Shop (the bed), About,
FAQ, Contact. Keep it simple.

## Step 8: Email popup (5 min)
Easiest: install the free **Shopify Forms** app (or use the email signup in the theme).
Paste the popup headline + subtext from `store-copy.md`. Set it to offer the 10% code.
This recovers visitors who don't buy right away. Organic traffic is precious, capture it.

## Step 9: Reviews app (5 min)
Admin → **Apps** → search **Judge.me** (free tier) → install. Add the seed reviews from
`store-copy.md` so the product page isn't empty. Real reviews replace them over time.

## Step 10: Domain + launch (10 min)
- Admin → **Settings** → **Domains**. Buy a domain (calmpaws.co or similar, ~$10-15/yr) or
  connect one you own.
- **Check everything on your phone.** 90%+ of your traffic is TikTok on mobile. Scroll every
  section on a phone screen.
- Go live: Admin → **Online Store** → **Preferences** → remove the password page.
