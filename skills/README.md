# Skills

The skills you're deliberately building. Track each one as it moves through the
stages. The goal isn't to list everything you could learn — it's to keep a short,
honest view of what you're actually practicing right now.

## Stages

| Stage | Meaning |
|---|---|
| 🎯 **Chosen** | Decided to learn it; haven't really started. |
| 📚 **Learning** | Actively studying the fundamentals. |
| 🔨 **Practicing** | Using it on real work; still clumsy. |
| ✅ **Fluent** | Can do it reliably without much friction. |
| 🏆 **Teaching** | Good enough to explain it to others. |
