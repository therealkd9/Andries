# Andries

> Building something out of nothing — a rebrand, a skill set, a body of work.

This repository is a personal operating system. It's not an app (yet); it's the
place where the work of becoming happens in the open: deciding who Andries is,
choosing what to learn, practicing until it sticks, and shipping things that
prove it.

The point is momentum. A goal that lives only in your head is fragile. A goal
written down, broken into skills, and reviewed every week starts to compound.

## How this repo is organized

| Folder | What it's for |
|---|---|
| [`brand/`](brand/) | Who Andries is becoming — identity, values, and how you show up. |
| [`skills/`](skills/) | The skills you're building, tracked from *learning* → *fluent*. |
| [`learning/`](learning/) | A running log of what you studied and what you took from it. |
| [`projects/`](projects/) | The things you create. Each gets a short brief. |
| [`goals/`](goals/) | The roadmap, and a weekly review to keep it honest. |

## The loop

1. **Set direction** — define the brand and the goals (`brand/`, `goals/`).
2. **Pick a skill** — add it to the tracker (`skills/`).
3. **Learn deliberately** — log sessions and notes (`learning/`).
4. **Build proof** — turn the skill into a project (`projects/`).
5. **Review weekly** — what moved, what stalled, what's next (`goals/weekly-review.md`).
6. Repeat. Each lap leaves a trail you can look back on.

## Getting started

Open [`goals/roadmap.md`](goals/roadmap.md) and write down one thing you want to
be true in 90 days. Then add the first skill it requires to
[`skills/README.md`](skills/README.md). That's it — you've started.
